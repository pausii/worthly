# Kode Etik

Proyek ini mengikuti [Contributor Covenant](https://www.contributor-covenant.org/id/version/2/1/code_of_conduct/) versi 2.1.

Ringkasnya: bersikap hormat, terbuka pada kritik yang membangun, dan fokus pada apa yang terbaik untuk
proyek. Pelecehan, hinaan, dan serangan pribadi tidak diterima dalam bentuk apa pun, di issue, PR,
maupun kanal lain yang terkait proyek.

Pelanggaran dapat dilaporkan ke maintainer lewat GitHub (mention `@pausii` atau pesan pribadi).
Semua laporan ditangani secara rahasia.
